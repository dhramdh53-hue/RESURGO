# RESURGO — DK Brand Hub

A responsive, single-page storefront for RESURGO, using the tagline “Wear your comeback.” The first-drop product catalogue includes graphic tee concepts inspired by the designs shared in the project conversation; each is listed at ₹699.

## Preview locally

Open `index.html` in a browser. The catalogue filters, add-to-bag counter, and newsletter confirmation are front-end demonstrations; checkout, email collection, and order fulfillment are not connected to a backend.

## Publish

The site is static and can be hosted on GitHub Pages or another static host. To use a custom domain, configure it with the hosting provider and add the domain in the repository's Pages settings. No domain name was provided yet.
